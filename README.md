# Color Toggle Button

A simple button that changes the background color of a box when clicked, alternating between two colors and updating the button text accordingly.

What I learned

Selecting DOM elements with getElementById
Handling click events with addEventListener
Using if/else to toggle between two states
Changing styles and text dynamically with JavaScript (style.backgroundColor, textContent)

How to run
Open index.html in your browser, or try the live demo below.
